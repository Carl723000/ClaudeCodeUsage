# v2.4 Provider 交互一致性矩阵

快照日期：2026-09-11；本地候选分支：`codex/v2.3.2-project-usage-matrix`。提交号只是开发
证据，不代表已发布版本的声明。

本矩阵记录交互一致性，但不假装 Claude 与 Codex 提供了等价数据。“已对齐”表示用户
交互与视觉层级一致；“刻意不同”表示现有来源证据无法支持同一行为；“部分完成”表示
仍有已知契约需要实现或验证；“本地候选”表示行为只存在于本地分支，并已通过表中所列
测试。

## 读取与持久化边界

| 交互 | 激活时允许读取的来源 | 跨 Webview 重载保留 | 重置边界 |
|:--|:--|:--|:--|
| 今日小时选择 | 无；只操作 DOM 状态 | 所选小时与所选指标 | 用户切换顶层仪表盘标签 |
| 最近 30 天“日 → 小时”（Claude） | 只使用已物化的 Webview DTO；不发送主机消息 | 展开日期与指标 | 用户切换顶层仪表盘标签 |
| 最近 30 天“日 → 小时”（Codex） | 只使用已物化的 Webview DTO；不发送主机消息 | 展开日期与指标 | 用户切换顶层仪表盘标签 |
| 全部时间“月 → 日”（Claude） | 只使用已存在的内存记录；不读取文件系统 | 展开月份与指标 | 用户切换顶层仪表盘标签 |
| 全部时间“月 → 日”（Codex） | 主进程用内存索引聚合返回一个带 provider 标识的所选月份片段；不读取文件系统 | 展开月份、可用的嵌套小时及指标 | 用户切换顶层仪表盘标签 |
| 排序/筛选 | 只使用已渲染 DTO | 排序、会话范围和模型筛选 | 用户显式修改或重置 UI |
| 项目矩阵范围／视图／展开 | 只使用有界项目日期 DTO；不发送主机消息，不读取文件系统 | 按 provider 保留 30／90 天范围、热力图／趋势视图和展开行状态 | 重置 UI |
| 滚动 | 只记录浏览器滚动位置 | 按 provider 和仪表盘标签保存 | 重置 UI |
| 实时数据替换 | 新渲染的 provider 面板 HTML、有界 Claude 滚动小时 DTO，以及按需返回的 Codex 单月片段；客户端不读取来源日志 | 当前标签、展开链、图表/小时选择、聚焦控件的临时值、键盘焦点和最近可见锚点 | 页面骨架变化、provider 切换、投递被拒或重置 UI |

本表中的任何交互都不得触发 JSONL 重扫。新增聚合必须在既有索引/更新流程中构建，并先
通过有界 DTO 传入 Webview，才能增加新的下钻控件。
