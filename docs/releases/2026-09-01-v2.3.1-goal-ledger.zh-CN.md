## G3 额度观测与周额度估算证据

### 持久化观测边界

- 新增带 schema 版本、按 provider/账号/窗口分区的观测存储，账号与窗口仅使用机器本地 HMAC fingerprint。原始凭证和身份信号完成摘要后立即丢弃；Webview 只能收到本次运行内的临时别名。
- 写入采用同目录 `0600` 临时文件、`fsync` 和原子 rename；跨进程 lease、锁内重读、规范化去重、180 天保留期及有界压缩保证重复刷新稳定且不合并账号 epoch。
- 严格校验会隔离损坏或未来 schema 文件，而不是信任或删除它们。P3/P4 globalState 旧观测及 P5 Codex index history 均先写入 P2，只有目标 append 成功后才清理源键或推进迁移 marker，因此中断后可安全重试。
- Claude 的账号连续性只在额度请求成功后由 refresh token 的单向 HMAC 得到；token 本身不返回、不持久化、不记录日志、也不进入 Webview。Codex 观测使用同一存储及隐私投影。

### 重置检测与额度推断

- reset 事件在运行时依据 provider window identity、`resetAt` 变化或 used 百分比显著回落推导。单纯账号切换不会伪造官方重置；同日多次及连续两日重置均保留为独立事件。
- 每个满足 `0 < usedFraction ≤ 1` 的有效观测都会形成“截至 observedAt 的已定价用量 ÷ usedFraction”候选总额度；多个候选用加权稳健中位数合并，并由定价覆盖、日志覆盖、边界精度和账号归属共同决定可信度。
- 总额度估算绝不低于窗口已确认使用值；未用值强制非负。当前窗口存在有效真实观测但账号/边界近似时，可以显示明确标为低可信度的总额与未用耐用度估算；已结束窗口若存在竞争性重叠系列则仍只显示已用值。
- 不存在有效观测、竞争性系列无法归一，或观测后新增用量已超过候选总额时，不显示未用值；最后一种情况只保留低可信度总额下界，不把未知伪装成 `$0`。
