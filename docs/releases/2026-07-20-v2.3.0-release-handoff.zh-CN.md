## V2.3.0 实际范围

1. **Codex Beta 默认开启、可关闭**：只发现 Codex home 下的
   `sessions/**/*.jsonl` 与 `archived_sessions/**/*.jsonl`，不读取 credential、
   SQLite、浏览器或 Keychain 数据；自定义 Codex home 仍可配置。
2. **Provider-native 数据模型**：Claude 保留原有成本与配额语义；Codex 使用
   processed、fresh、cached input、output、reasoning、model、effort、root／child／
   approval-reviewer、coverage、quality 和 last-observed limit，不虚构 Codex 成本。
3. **Claude／Codex／Compare 仪表板**：Claude-only 显示 Claude，Codex-only
   自动显示 Codex；两者都有时默认 Claude。Codex 复用现有 Claude 面板的标签、卡片、
   柱状图、Token 构成图和表格视觉，提供最近任务、7 天、30 天、全部时间、线程、项目、
   行为与设置八个标签。Session 标题来自 Codex 自己的标题索引；项目名来自 Git 仓库名
   或非 Git 目录 basename；线程支持名称搜索、四类筛选、排序、父子折叠和项目下钻。
   Compare 只并列 input、output、cache，不把不同 provider 的 cost 或 quota 相加。
4. **本地用量优化建议**：默认开启、可在 Settings 关闭；Behavior 可切换最近任务、
   7 天、30 天和全部时间，用结构化汇总识别高 effort、多 agent、自动审批审阅、
   重复检查代理指标和低缓存模式；提供八种 UI 语言的可直接粘贴约束。无需模型调用，
   不检查、不使用、不保存 prompt、response、command 或 tool-argument 正文。
5. **可扩展索引**：Codex 扫描在可取消 worker 中运行，按文件持久化带机器 salt 的
   HMAC key 与数字聚合；支持 append tail、truncate／replace、archive move、失败保留
   上次可信 contribution、single-flight 和 dispose。
6. **低 CPU 默认值**：Codex watcher 默认 30 秒 quiet delay，可选 Off／10／30／60／
   120／300 秒；watcher 只请求 worker refresh，不在 Extension Host 解析正文。
7. **准确的 rollout 语义**：真实历史证明 child counter 从自己的零点开始；重复
   metadata 不再抹掉 lineage；正常的 `world_state`、`compacted`、
   `inter_agent_communication_metadata` 不再误报质量问题；`guardian` 会话归入
   approval-reviewer。OpenAI 官方说明自动审批由 reviewer agent 执行、默认 policy
   位于 guardian 模块，而且会增加模型调用：
   <https://learn.chatgpt.com/docs/agent-approvals-security#automatic-approval-reviews>。
8. **发布体验清理**：升级提醒只匹配完整的当前版本，不再回退显示旧 V2.2 内容；
   选项默认打开但可关闭。过时的模型专属每周上限设置已移除，通用 5 小时／每周配额
   保留；PR #38 与 @wheelbarrel00 的历史贡献署名保留。
9. **文档与维护规范**：八种 UI locale、七份 README、英文／中文版架构与 spec 已同步；
   Codex 主写 commit 使用真实 OpenAI Codex co-author trailer 与 Codex footer。
10. **额度与设置对齐**：详情页按真实 `limit_id` 显示全部未过期的 primary／secondary
    窗口、重置时间与 credits；Codex Settings 只显示共享项和 Codex 实际有效项，当前页
    的“重置全部”不会重置另一提供方的隐藏设置。

## 已知 Beta 边界

- Codex limit 只是日志中**最后观测**到的快照，不是实时账单或官方订阅余额；过期后隐藏。
- 不展示 Codex 美元成本；processed、fresh、cache、reasoning 的定义在 UI 与 README 中
  明示。
- “修改文件数”是 `apply_patch` 轮次的隐私安全下界；“修改后命令”是结构性代理指标，
  都不会读取工具参数或命令正文，也不声称因果关系。
- 第一次 2.61 GB backfill 约 9.8 秒，工作在 worker 中；仍有两个活跃 rollout 追加时的
  warm refresh 为 38 ms。旧索引首次补全身份时，每个缺失文件最多只读开头 256 KiB；
  补全后未变化文件仍为零 body read。
- 当前只完成 macOS 安装／激活 smoke；Linux CPU 仍建议在 PR prerelease 或合并后观察。
- 产品在 Beta 期间继续使用 `Claude Code Usage` Marketplace identity；是否改名或拆包留到
  采用率复盘，不在 V2.3.0 中变更。
